Three clicks, start to finish

No setup screen, no extra menu to learn.

1

Install the app

The Preview action appears automatically on every attachment, everywhere in Odoo.

2

Click Preview

From the attachment list, its form, or a record’s attachment panel.

3

View it instantly

The file opens in a new tab, already rendered — no download folder involved.

Built with access control in mind

Nothing here bypasses Odoo’s own permission rules.

The viewer page runs under the requesting user’s own permissions — never with elevated access.

Standard ir.attachment access rules decide what each user is allowed to open.

A visitor who isn’t logged in is sent to the login page, never to a file.

Large text files are capped at a configurable size, so a big log can’t freeze the tab.
